# Agentic AI SOC-in-a-Box
By the end of 14 weeks, the student will present a fully functional virtual lab that showcases an end-to-end SOC workflow. This includes an attack simulation, telemetry collection, detection alert, AI-assisted triage, automated response playbook, evidence artifacts, and a final demonstration.

## Functional Capabilities
Telemetry Pipeline: Target VM events are reliably captured and can be searched.
Detections: Eight to ten working detections are documented and tested against various scenarios.
Reproducible Attack Scenarios: Three reproducible attack scenarios are provided, either as scripted scripts or clearly repeatable runbook steps.
SOAR Workflows in n8n: The workflows are designed to ingest alerts, enrich them, call agents, generate case artifacts, and execute response actions.
Agentic AI Triage: The triage process produces strict JSON outputs with validated schemas, evidence-based rationales (event IDs and timestamps), playbook selection, and guarded execution.
